Layer 6: Presentation & Adapters

18 decoupled CLI runner scripts and isolated domain-specific MCP tool handlers (graph, lookup, search, verification).

Layer 5: Service & Application

Unified QueryService facade, AST mutation engine, and deterministic pipeline phase executor.

Layer 4: Pipeline Middleware

8 single-responsibility PipelinePhase handlers executing sequentially over shared PipelineContext.

Layer 3: Canonical Graph Engine

Immutable CanonicalGraphQuery, global scope-stack symbol table, and atomic .coderef/ index storage.

Layer 2: RAG & Search Substrate

3-character BM25 sub-token sparse index + dense vector store + Reciprocal Rank Fusion (RRF) reranker.

Layer 1: Core Parser Substrate

Tree-Sitter multi-language Wasm/native grammar registry, language AST visitors, and LRU scan cache.
