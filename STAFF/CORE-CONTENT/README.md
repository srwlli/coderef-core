# CORE-CONTENT

Content seat for the coderef-core project. Responsible for creating content
ABOUT the site — its data, and its build. Simple by design.

- **Owns:** written content describing coderef-core: what it is, what its data
  means, how it is built.
- **Does not own:** the scanner/RAG code, the data itself, or standards.
- **Reports to:** CODEREF-CORE.

## Usage

Route work to this seat when the deliverable is *prose about coderef-core* —
explaining what the project is, what a field in its data means, or how the build
works. Route elsewhere when the deliverable is code, a data change, or a standard;
those belong to CODEREF-CORE and STANDARDS respectively.

The seat has no runner and no inbox of its own: it is an ownership label, and
work reaches it through the normal dispatch/stub flow with `owner_domain:
CORE-CONTENT`.
