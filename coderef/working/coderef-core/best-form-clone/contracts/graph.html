The 10 laws (what the rules gate enforces)
L1 — One codec per artifact: every artifact is read and written only through its contracts codec, and every codec ships a round-trip property test. (kills P1)
L2 — Single parse: one AST session per file per run; every extractor rides the same walk. (kills P1)
L3 — One adjacency index: exactly one graph store; every query surface reads it. (kills P2)
L4 — Zero-logic adapters: transports import engine.api and nothing else; handler bodies are schema-map + call, size-budgeted in CI. (kills P2, P3)
L5 — Deny-by-default imports: an import edge not present in blueprint.json fails verify.rules in CI. (kills P3, P6)
L6 — Branded paths: repo-relative POSIX RepoPath at every boundary; raw path strings die at the loader. Windows is a first-class CI target. (kills P5)
L7 — Honest numbers: denominators and exclusions are owned by engine.measure; every artifact and response carries the staleness envelope; readers distinguish empty from unknown. (kills P4)
L8 — Engine-repo purity: no planning trees, no process machinery, no generated output inside scan scope — allowlist discovery makes pollution structurally impossible. (kills P6, P8)
L9 — Cycles pinned at zero inside the engine from the first commit. (kills P3)
L10 — Delete, don't quarantine: superseded code is removed in the same phase its replacement proves parity. No legacy doors. (kills P3, P6)

contracts.pathscontractsP0*Branded repo-relative POSIX path type. Construction and normalization happen only at boundaries (loader, codecs, adapters); raw path strings die on entry. Windows-first test matrix.
contracts.indexcontractsP0*File + element records: identity (@Type/file#name:line), spans, exports, docstrings. The artifact every downstream reader joins on.
contracts.graphcontractsP0*Node/edge kinds, resolution provenance enum, confidence tiers, evidence blocks. One vocabulary for every edge the system will ever emit — a new edge kind is a schema change here, and every reader learns it at compile time.
contracts.mapcontractsP0*MapData projection: dir/file nodes, aggregated edges, overlays, analytics blocks. Exactly what surface.viewer renders — versioned so viewer and engine can never silently disagree.
contracts.headerscontractsP0*Semantic-header grammar with generator and parser as ONE co-located codec, round-trip property-tested: parse(generate(x)) === x for all x. The hash-asymmetry class dies here.
contracts.ragcontractsP0*Chunk records, embedding metadata, scoring envelope. Joins to contracts.index by element id — never by header presence.
contracts.envelopecontractsP0*Provenance + staleness block REQUIRED on every artifact and every query response. Readers must distinguish empty (measured zero) from absent (no data). Vector-vs-index and source-vs-graph axes both stamped.
engine.loaderengineP1AOwns scan scope: allowlist-first discovery (source globs in; build output, planning trees, and generated artifacts out by construction, not by ignore-file discipline). The only module that walks the filesystem.
engine.extractengineP1ASingle-walk extraction: elements, raw call/reference sites, and docstrings ride ONE traversal. An extractor that sees frames the others skip (the arrow-function class) is structurally impossible — there is only one walk.
engine.resolveengineP1AImport-origin classification and call-resolution tiering. Every edge is stamped with provenance and confidence from contracts.graph — an unstamped edge cannot be constructed.
engine.graphengineP1ABuilds the canonical graph and owns THE single adjacency index. Every query path — MCP, CLI, analytics, surfaces — reads this one structure.
engine.analyticsengineP2ACycles, hotspots, impact BFS, path search, clones, ast-metrics, and the map projection (emits contracts.map artifacts) — pure functions over the one graph.
engine.measureengineP2AOwns every published number: denominators, unresolved taxonomy, exclusions applied at the source (never left to ignore files). No consumer computes its own counts.
engine.ragengineP1DChunking, embedder port (local Ollama adapter), BM25 sub-token index, RRF fusion. Consumes contracts.index; fully functional on repos with zero headers.
engine.headersengineP2DEmits and refreshes semantic headers exclusively through the contracts.headers codec. Optional everywhere — nothing downstream requires headers to exist.
engine.apiengineP1BTHE typed facade. Every query and command the system offers is a function here; transports may import nothing else. MCP/CLI parity is by construction — there is no second implementation to drift.
surface.viewersurfacesP1CInteractive map web app. Reads MapData artifacts (contracts.map) and nothing else — it must render a fixture artifact with no engine installed.
surface.docgensurfacesP1CResource sheets, foundation docs, READMEs generated from index + graph artifacts. Lives outside the engine so doc churn never dirties the scan loop.
surface.packsurfacesP1CToken-budgeted context packs and change dossiers assembled from index, graph, and RAG artifacts.
verify.driftverificationP2*The clone's own map, diffed against this blueprint. As-built converges on as-designed visibly, every build.
